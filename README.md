# Pratham's Portfolio

A modern, interactive personal profile and portfolio website showcasing skills, expertise, and professional background.

## 🚀 Overview

This is a sleek, responsive portfolio site designed to present a professional full-stack engineer and AI enthusiast. The site features a hero section with smooth animations, elegant navigation, and detailed information about skills and experience. More changes can be made in this. The skeleton is commented in the index.html. So, you can use that. 

## ✨ Features

- **Hero Section** - Eye-catching landing area with parallax scroll effects
- **Responsive Design** - Mobile-friendly layout that works on all devices
- **Smooth Animations** - CSS transitions and JavaScript scroll effects
- **Modern Styling** - Clean, minimalist design with glassmorphism effects
- **Navigation Menu** - Quick access to different sections (Hero, Brief, Contact)
- **About Me Section** - Detailed professional background and expertise

## 🛠️ Tech Stack

- **Frontend Framework**: HTML5, CSS3, JavaScript (jQuery)
- **Styling**: Tailwind CSS for utility-first styling
- **Fonts**: Google Fonts (Cutive Mono)
- **Effects**: CSS animations, parallax scrolling, blur effects
- **Layout**: Flexbox and CSS Grid

## 🚀 Getting Started

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Navigate** through the sections using the header menu
4. **Scroll** to see animations and parallax effects

### Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for external fonts and Tailwind CSS CDN)

## 📖 Navigation

- **Hero** - Landing section with introduction
- **Brief** - About Me / Professional background
- **Contact** - Get in touch (coming soon)

## 🎨 Customization

- Modify `style.css` to change colors and layout
- Update `index.html` to add or modify content
- Adjust animations in `script.js` for different effects
- Replace `assets/hero-bg.png` with your own background image
